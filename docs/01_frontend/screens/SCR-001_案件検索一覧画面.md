# 案件検索一覧画面

画面ID: SCR-001
画面名: 案件検索一覧画面

---

## 1. 概要
案件を検索条件で絞り込み、検索結果を一覧表示する画面。

---

## 2. 画面目的
- 案件を検索する
- 案件の主要情報を一覧で確認する
- 結果件数を表示する

---

## 3. 画面構成
- header: 画面タイトル
- searchArea: 検索条件入力
- actionArea: 検索・クリアボタン
- messageArea: 件数・情報・エラーメッセージ表示
- resultArea: 検索結果一覧

---

## 4. 入力項目

| ID | ラベル | 種別 | 型 | 必須 | 初期値 | 備考 |
|----|--------|------|----|------|--------|------|
| projectName | 案件名 | text | string |  | "" | 部分一致検索 |
| nationalityAllowed | 国籍可否 | select | string |  | "" | 値: "", "可", "不可", "要確認" |

---

## 5. ボタン

| ID | 表示名 | 処理 | 備考 |
|----|--------|------|------|
| searchBtn | 検索 | 検索条件でダミーAPIを呼び出す | |
| clearBtn | クリア | 検索条件、結果、メッセージを初期化する | |

---

## 6. 検索結果一覧項目

| 項目ID | 表示名 | 型 | 備考 |
|--------|--------|----|------|
| projectId | 案件ID | string | 一意キー |
| projectName | 案件名 | string | |
| location | 勤務地 | string | |
| maxUnitPrice | 上限単価 | number | 単位: 万円 |
| nationalityAllowed | 国籍可否 | string | 可 / 不可 / 要確認 |

---

## 7. 初期表示
- projectName は空文字
- nationalityAllowed は未選択
- items は空配列
- totalCount は 0
- loading は false
- errorMessage は空文字
- infoMessage は空文字

---

## 8. 動作仕様

### 8.1 検索ボタン押下
1. 検索条件を取得する
2. ダミー検索APIを呼び出す
3. 検索結果を一覧表示する
4. totalCount を表示する
5. 0件の場合は情報メッセージを表示する
6. 失敗時はエラーメッセージを表示する

### 8.2 クリアボタン押下
1. 検索条件を初期化する
2. 検索結果を空にする
3. 件数を0にする
4. メッセージをクリアする

---

|------|----|------|------|

```json
{

    {

```

## 13. 使用コンポーネント

| コンポーネント名 | 役割 |
|-----------------|------|
| ProjectSearchPage | 画面全体管理 |
| ProjectSearchForm | 検索条件入力 |
| ProjectSearchActions | ボタン表示 |

| ProjectResultTable | 一覧表示 |

---

## 14. スタイル方針
- 業務画面向けのシンプルなテーブルレイアウト
- 最大横幅 1000px
- 余白は広めにし、視認性を優先する
- テーブルヘッダは識別しやすい背景色を付与する

---

## 15. 実装指示
- 画面はコンポーネント分割すること
- 検索条件は state で管理すること
- API は services 層から呼び出すこと
- 取得データは配列ループで描画すること
- 純HTML/CSS/JavaScriptでも実装可能な構造とすること
